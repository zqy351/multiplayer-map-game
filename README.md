# 大地图探险 · 多人联机小游戏

一个开箱即用的多人联机小游戏：在 6000×6000 的广阔地图上奔跑、捡金币、比得分。

## 玩法
- 房主点击「创建房间」，把 5 位房间码发给朋友
- 朋友输入房间码「加入房间」，即可同场游玩
- WASD / 方向键 / 手机虚拟摇杆移动，碰到金币得分
- 所有玩家地图完全一致，位置与得分实时同步

## 技术说明
- 纯前端单文件（HTML + Canvas），无需自建服务器
- 基于 PeerJS（WebRTC 点对点）联机，房主做状态中转
- 地图由固定种子程序化生成，各端一致
